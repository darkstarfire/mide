# Interface das extensões do Zed (WIT)

Os arquivos `.wit` desta pasta são a interface das extensões do editor Zed
(`crates/extension_api/wit/since_v0.6.0` de github.com/zed-industries/zed), licença
Apache-2.0 (`LICENSE-APACHE`), copiados sem mudanças para o Code do mide rodar as
extensões compiladas para essa interface (`zed_extension_api` 0.6 e 0.7). O lado
do mide (o "host", `src/code/wasm_ext.rs`) é escrito do zero.
